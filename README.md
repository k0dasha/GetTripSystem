GetTripSystem(GTrip) - информационная система, предназначенная для автоматизации процесса сбора в поход среди туристов.

Для запуска проекта необходимо:
1)	Установить .NET 10 SDK
2)	Установить Git
3)	Установить систему PostreSQL и GUI pgAdmin 4
4)	Склонировать проект с GitHub с помощью командной строки: git clone https://github.com/k0dasha/GetTripSystem.git
5)	Перейти в скопированный репозиторий
6)	Открыть файл .sln
7)	Убедиться в соответствии указанного в файле проекта App.xaml.cs пароля суперпользователя postgres с установленным паролем в своей системе 
8)	Запустить проект, нажав F5 или кнопку Run
